# CLERWELL Policy Decision Assistant Assignment

This is the candidate package for a focused 3-5 hour Generative AI engineering exercise.

Start with `ASSIGNMENT.md`. The required desktop interface and result contract are defined in `UI_REQUIREMENTS.md` and `OUTPUT_SCHEMA.md`.

## Package contents

- `ASSIGNMENT.md` - complete candidate brief
- `policies/` - five fictional company policies
- `data/requests.json` - 20 employee, customer, and vendor requests
- `examples/` - illustrative input and output only
- `UI_REQUIREMENTS.md` - required PyWebView screens and interactions
- `OUTPUT_SCHEMA.md` - required structured result
- `SUBMISSION_CHECKLIST.md` - candidate hand-in checklist
- `requirements-template.txt` - suggested dependencies; candidates may replace it

The package contains no answer key or reference implementation.
